贪婪扩展算法步骤
初始状态
推测子树 T = {Nₚ} 只有起始节点
子树大小 |T| = 1
循环执行
while |T| < MAX_SPEC
1
找出 T 中所有叶节点
叶节点是推测树中没有子节点的节点
2
收集叶节点的所有子节点 → 候选集合 S
这些是可能被加入推测树的节点
3
计算每个候选节点的 D 值
D = 从 Nₚ 到该节点的路径概率
4
选择 D 值最大的节点 N*
贪婪策略：优先选择最可能被接受的
5
将 N* 加入推测树 T
6
更新大小 |T| += 1
📤
返回
T 作为最终的推测树
pseudocode 
def greedy_expand(Np, MAX_SPEC):
    T = {Np}
    
    while len(T) < MAX_SPEC:
        leaves = get_leaves(T)
        S = get_children(leaves)  # 候选集合
        
        if S == ∅: break  # 无候选节点
        
        N_star = argmax(D(n) for n in S)
        T.add(N_star)
    
    return T
