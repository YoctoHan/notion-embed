模式匹配流程
❌ 情况 A：模式未找到
模式序列
["weird", "unique", "pattern"]
       (root)
      /   |   \
    ":"  "def"  "return" ...

第1步：找 "weird" → 不存在！
处理方式
回退到标准解码（逐 token 生成，无投机）
⚠️ 当前模式在历史中从未出现过
✅ 情况 B：模式找到
遍历结果
成功遍历 p 步后到达 Nₚ
        [Nₚ]  ← 到达的节点
     /   |   \
   子1  子2  子3   ← 候选续写
    |    |    |
   ...  ...  ...   ← 下降路径
下降路径 (Descending Paths)
从 Nₚ 往下的所有可能路径，每条路径代表一个候选续写序列
🎯 可以进行投机解码！
关键理解
模式匹配决定了是否能够进行投机解码：

• 匹配成功 → 到达节点 Nₚ，其子节点就是候选续写的起点
• 匹配失败 → 无法利用历史信息，回退到普通解码
