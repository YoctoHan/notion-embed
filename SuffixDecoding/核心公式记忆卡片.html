COUNT(N)
COUNT(N) = 节点 N 在语料库中出现的次数
C
C(N)
C(N) = COUNT(N) / Σ(兄弟节点的 COUNT)
  • 局部转移概率
  • "到达父节点后，下一步走到 N 的概率"
D
D(N)
D(N) = {
D(父节点) × C(N) if N ≠ Nₚ
1 if N = Nₚ
  • 从 Nₚ 到 N 的路径概率
  • "TOKEN(N) 被验证接受的估计概率"
⚡

每次添加 D 值最高 的候选节点，
直到达到 MAX_SPEC 限制
NOTE：C 是局部概率，D 是全局概率
